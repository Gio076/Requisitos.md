# Requisitos.md
Descrição breve dos Requisitos Funcionais(RF), Requisitos Não Funcionais(RNF) e das Regras de Negócio(RN).

## Requisitos Funcionais(RF):
1.Cadastrar os Produtos;
2.Cadastrar entrada e saída de produtos;
3.Cadastrar o Organizador do almoxarifado.

## Requisitos Não Funcionais(RNF): 
1.O Site deve funcionar em computadores, tablets, e telefones;(Responsividade)
2.O Site deve funcionar no chrome, no google e no edge;
3.O Site deve ter um tempo de reposta de 5 seg;

## Regras de Negócio(RN):
1.Apenas pessoas entre 16 e 60 anos podem trabalhar no almoxarifado e se cadastrar no site;
2.Cada produto deve ter o seu valor;
3.Não pode cadastrar valores negativos;
4.Apenas pessoas cadastradas podem acessar o site.
